¿Qué es el hardware?

El hardware es el conjunto de componentes físicos de un ordenador.

Principales componentes

Los componentes principales de un ordenador son:

  • Procesador (CPU)
  • Memoria RAM
  • Placa base (Motherboard)
  • Disco duro (HDD) o unidad de estado sólido (SSD)

Funciones del hardware
Componentes Función principal
Procesador (CPU) Ejecuta instrucciones
Memoria RAM Almacena datos y programas en uso
Placa base (Motherboard) Conecta todos los componentes del ordenador
Disco duro (HDD) o unidad de estado sólido (SSD) Almacena datos de forma permanente
Tarjeta gráfica (GPU) Procesa y renderiza gráficos
